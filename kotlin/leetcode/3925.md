class Solution {

## 解題思路

這題目是陣列相關操作

透過 Kotlin 內建的 `reversedArray()`

可以很快的處理掉這一題

## Kotlin 參考解答

<details>
  <summary markdown='span'>點擊展開解答</summary>

```kotlin
class Solution {
    fun concatWithReverse(nums: IntArray): IntArray {
        return nums + nums.reversedArray()
    }
}
```
